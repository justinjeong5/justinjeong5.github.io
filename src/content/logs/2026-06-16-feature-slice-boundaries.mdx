한 화면에서만 쓰는 상태와 API 경로를 공용 폴더에 두면 다른 기능도 그 내부 구조를 알아야 할 수 있다.

그래서 기능 안에서 쓰는 상태와 API 경로는 그 안에 두고, 여러 기능이 함께 쓰는 계약만 공유 영역에 올리는 방향을 검토했다.
