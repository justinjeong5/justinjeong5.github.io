## 당시 기록에서 남긴 질문

원본 회고는 기차 예매 화면을 옮기는 개인 실험의 모듈 경계를 다뤘다. 화면 재현 학습과 실제 서비스 운영 경험은 구분한다.

기능 전용 상태와 API 경로는 기능의 범위에서 다루고, 여러 기능이 함께 쓰는 계약만 공유 영역으로 올린다는 선택을 읽는다.

이 글은 이전 회고를 다시 편집한 기록이다. 당시의 실행·출시·효과를 이번 사이트 정리로 새로 검증한 성과와 혼동하지 않는다.
