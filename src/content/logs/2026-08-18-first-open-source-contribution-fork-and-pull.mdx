## 당시 기록에서 남긴 질문

원본 회고는 PokeTokenBar의 Antigravity 데이터 경로·기존 호출자 호환·알림 권한 요청의 동시성 문제를 다뤘다. 이번 정리에서는 공개 PR 상태나 기여 결과를 조회하지 않았다.

여러 실행 환경의 UI 통합 단위와 새 경로의 중복·구형 호출자를 어떻게 다룰지가 질문이다. 전후 설명과 재현 자료는 검토를 돕지만 머지·사용자 효과를 증명하지 않는다.

이 글은 이전 회고를 다시 편집한 기록이다. 당시의 실행·출시·효과를 이번 사이트 정리로 새로 검증한 성과와 혼동하지 않는다.
