## source까지 연결되는 변경

개인 채팅 프로젝트의 공개 PR에서 WebSocket transport 설정과 메시지 전달, 화면의 상태 갱신을 변경한 기록이 있다. REST 전송 후 응답 상태를 바꾸는 경로 대신 메시지 이벤트를 전달하고, 받은 메시지는 functional update로 반영하는 변경이다.

별도 PR에는 방 입장/퇴장 UI와 이벤트가 있다. membership API와 UI의 이동, 이벤트 통지, 연결 등록과 화면 정리 경로를 연결한 좁은 작업이다.

## 개인 프로젝트와 업무 운영은 다르다

작성자·선택 diff·병합 기록은 해당 변경의 근거다. 현재 파일 전체의 최초 작성이나 단독 소유, 실제 다중 client의 실행·상용 출시·재접속/오프라인 신뢰성을 자동으로 증명하지 않는다.

기존 글의 이용자 수·오류율·시간 비율이나 무료 호스팅의 조건을 현재 성과로 사용하지 않는다. 개인 작업은 기술 접점과 학습의 보조 근거로 둔다.
