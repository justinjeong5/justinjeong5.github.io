## 새 글을 추가하는 경계

이 사이트의 case/note/essay는 MDX 파일과 frontmatter로 구성되고 content 모듈이 이를 인덱싱한다. 표현은 페이지 컴포넌트가 맡는다. 글의 추가와 페이지의 코드를 매번 같이 바꾸지 않도록 나누는 구조다.

파일 이름은 공개 경로와 내부 링크에 연결된다. 글을 통합할 때는 기존 주소의 안내를 유지하거나 모든 역참조를 함께 정리해야 한다.

## 파일 기반이라고 검증이 사라지지 않는다

필수 metadata, 내부 링크, 공개할 정보와 글의 상태를 검사한다. 보관/통합된 글은 목록과 검색에서 제외하되 원래 주소로 접근할 수 있게 한다. 검색·관련 글·목록은 같은 노출 규칙을 사용해야 한다.

eager/lazy 로딩의 적절함은 파일 개수의 보편적인 임계보다 빌드 산출물과 실제 로딩 비용으로 판단한다. 여기서는 콘텐츠 수에 따른 고정 빌드 시간이나 성능 개선율을 보장하지 않는다.
