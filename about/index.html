정경하

6년차 프론트엔드 엔지니어 정경하입니다. 콘텐츠와 리워드 제품을 만들며 화면 안의 행동을 서버 상태, 외부 광고, 앱 복귀와 연결해 왔습니다. 사용자가 참여를 끝낼 수 있는 흐름을 만들고, 출시 뒤의 문제를 읽을 관측 구조까지 다룹니다.

맡아 온 일

  • 초기 허브에서 반복 참여 제품까지

    파트너 앱에서 광고·콘텐츠·미션에 참여하고 리워드를 받는 PlayHub 초기 허브의 핵심 FE를 구축했습니다. 상태와 광고 실행, 외부 복귀와 결과 안내를 연결하고 QA·매체 출시까지 이어 갔습니다.

  • 제품 지표를 지키며 상세 진단 줄이기

    KPI 이벤트와 상세 진단을 나누고 고정 기기 표본과 추가 조사 경로를 구현했습니다. 데이터 플랫폼팀과 적재·조회 분리를 협의하고 관리하던 조회의 이관을 마쳤습니다.

  • 동료의 반론을 설계 변경으로 연결하기

    공용 배포 도구의 규칙을 저장소 선언으로 옮기고, FE 앱의 전달 구조와 제품 QA 조건을 동료들과 다시 정했습니다. 무엇이 내 선택을 바꿨는지 구체적인 사례로 돌아봅니다.

함께 일할 때

  • 같은 화면보다 같은 의미를 먼저 맞춥니다

    앱과 웹의 모양은 달라도 같은 서버 상태에서 사용자가 할 수 있는 행동은 일치해야 합니다. 공통 규칙과 환경별 실행을 나누어 설계했습니다.

  • 팀의 병목이면 프론트엔드 밖의 일도 맡습니다

    AI와 서버 문의 기능·테스트를 준비하고 DBA의 DB 반영 뒤 병합을 이어 갔습니다. 낯선 영역에서는 허용할 입력과 부수효과, 담당자가 확인할 반영 순서를 먼저 정합니다.

  • 실제 사용에서 돌아온 질문을 구현에 넣습니다

    운영 화면의 완료 안내와 실제 상태가 어긋났을 때 처리 중 상태와 후속 조회를 추가했습니다. 요청 성공 뒤에도 사용자가 확인할 일이 남는지 봅니다.
